# Gestion des Employés - Java Swing

Une application desktop complète pour la gestion des employés (CRUD) développée en Java. Ce projet met en œuvre une architecture MVC propre et une interface graphique Swing.

##  Fonctionnalités
- Authentification sécurisée (Login / Mot de passe)
- Ajout, modification et suppression d'employés
- Recherche d'employés par matricule
- Tableau de bord avec liste complète des employés

## Technologies utilisées
- **Langage :** Java
- **Interface :** Java Swing
- **Base de données :** MySQL / MariaDB
- **Architecture :** MVC (Model-View-Controller), DAO
